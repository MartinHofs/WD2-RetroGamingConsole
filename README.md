# WD2-RetroGamingConsole

---

Github Link: https://github.com/MartinHofs/WD2-RetroGamingConsole

---

Request:
    Before anything, app.js checks if it can get to the API. Once it does and the status check passes, it gets the response text and parses it into an object. With the object parsed, it goes through a process of making the cards for them.

---

Summary:
    It first creates an oldest item and a newest item. It then goes through the consoles and checks each one via two if statements. Once it gets the oldest and the newest, it puts the text in a bold element, which is put in the summary paragraph.
